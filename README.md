# [활동지 발표용 자료 사용법]
### 크롬에서 F11 을 누르면 전체 화면이 됩니다. 전체화면을 기준으로 제작한 웹입니다.
## [온라인 사용법]
   - https://liberali0.github.io/sns.profile.activity.sheet.presentation/ 
   - 위 링크에 접속 합니다.
## [오프라인 사용법]
1. 활동지_발표.html 과 images 폴더가 같은 곳에 있어야 합니다.
2. 활동지_발표.html 을 크롬(또는 엣지)으로 열면 인터넷 없이도 작동합니다.
3. 조작
   - 키보드 P (한글 상태면 ㅔ): 발표 모드 켜기/끄기
     활동지가 오른쪽으로 가고, 왼쪽에 지금 짚은 칸의 설명과 한대길 예시가 나옵니다.
     (창 너비가 좁으면 설명이 숨겨지니 F11 전체 화면에서 쓰세요)
   - → ↓ 스페이스바 또는 활동지 바깥 빈 곳 클릭: 다음 칸
   - ← ↑: 이전 칸
   - 활동지의 칸(프로필 사진, 아이디, 피드 등) 클릭: 그 칸으로 바로 이동 (한 번 더 클릭하면 전체 보기)
   - 숫자 1 / 2 / 3: 1쪽 프로필 / 2쪽 스토리 / 3쪽 작성 요령
   - Esc: 지금 쪽 전체 보기,  Home: 처음으로
  5. 설명 글은 활동지_발표.html 안의 CONFIG.steps 에서 고치면 됩니다.
   활동지 그림이 바뀌면 images 폴더의 p1.png, p2.png, p3.png 를 새 그림으로 바꾸세요.
